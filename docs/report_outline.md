# College report outline
1. Title, certificate, acknowledgement, abstract
2. Introduction: motivation, problem statement, objectives, scope
3. Literature survey: PII detection, NER, DLP tools, Microsoft Presidio, LLM privacy risks
4. Requirements: functional, non-functional, hardware/software
5. System design: architecture diagram, gateway flow, policy model, data model (SQLite), API
6. Implementation: detectors, validators, clustering/masking, policy engine, gateway, providers, frontend
7. Dataset and evaluation methodology: generator, metrics, threats to validity
8. Results: comparison table, per-category analysis, error analysis, latency
9. Testing: unit, integration (blocked prompts never reach provider), adversarial, UI
10. Security and privacy considerations
11. Limitations and future work
12. Conclusion; References; Appendices (API docs, screenshots, sample outputs)
